# Webstore design explorations

Eight store-section variations (header/nav, hero, categories, products, mailing list) as Design canvas artboards (`.dc.html`).

- `webstore-v1-riso-toy/`: A Sticker Sheet, B Riso Zine, C Toy Aisle, D Tape Deck
- `webstore-v2-headempty-system/`: E Trapper Keeper, F Desktop, G Order Form, H Gacha (all on the headempty.tools design system)

Each board shares the same content (six products, four categories, same copy) so they compare directly.
